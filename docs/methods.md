# 方法

このページは、月次レポートの数字と判定がどのように作られているかを説明します。計算はすべて公開しているプログラム（`src/situation/`）で行っています。

## 1. 考え方

生活困窮の相談では、本人や世帯の事情に目が向きがちです。しかし、物価・エネルギー・雇用・年金・制度の変化といった**本人の外側の動き**が、困りごとの一因になっていることがあります。このサイトは、それらを毎月同じ方法で観測し、相談の背景として考えられる「外的な一因」を整理するためのものです。

- 「原因」ではなく「一因」と書いています。相談の事情は複合的で、ここで示すのはその一部だけです。
- 判定の基準は**目安**です。公的な基準ではありません。
- 個々の相談者の情報は一切使っていません。

## 2. データと前年比

- 月次または四半期の公表統計を、出典から直接取得しています（「データの出典と利用条件」を参照）。
- 比べ方は原則として**前年同月比**です。季節による動き（冬の灯油など）を避けるためです。
  - 割合（%）や倍率の指標（失業率、有効求人倍率）は**前年同月との差**（ポイント）
  - すでに前年比として公表されている指標は、そのまま使います
- 年に一度だけ変わるもの（年金額、最低賃金）は、改定のあった月から次の改定まで同じ値が続くとして月次にしています。
- 世帯の支出は月ごとの振れが大きいため、**直近3か月の平均**で判定します。四半期の統計は最新の四半期を使います。
- 北海道の数字があるものは北海道を、ないものは全国の数字を使います。単身世帯の家計は「北海道・東北地方」までしか分かれていません。

## 3. 判定の基準

観点ごとに、最新の前年比を次の区分に当てはめています。左の値「以上」でその区分になります。

| 観点 | 区分（左の値以上でその区分） |
|---|---|
| 物価全体・医療費（保健医療）・たばこ・酒類 | 高い上昇（+3%以上）、上昇（+2%以上）、緩やかな上昇（+0.5%以上）、横ばい（-0.5%以上）、下落（それ未満） |
| 食料 | 大幅な上昇（+5%以上）、上昇（+2%以上）、横ばい（-2%以上）、下落（それ未満） |
| 灯油など（他の光熱）・灯油の店頭価格・電気代・円建ての原油価格 | 大幅な上昇（+10%以上）、上昇（+3%以上）、横ばい（-3%以上）、下落（それ未満） |
| 為替 | 円安が進んでいる（+5%以上）、大きな変化なし（-5%以上）、円高が進んでいる（それ未満） |
| 有効求人倍率 | 改善（+0.05ポイント以上）、横ばい（-0.05ポイント以上）、悪化（それ未満） |
| 完全失業率 | 悪化（+0.2ポイント以上）、横ばい（-0.2ポイント以上）、改善（それ未満） |
| 家計の支出・家計の支出（収入の低い世帯）・家計の支出（単身の勤労者世帯・北海道東北）・家計の支出（単身世帯全体・北海道東北） | 増加（+2%以上）、横ばい（-2%以上）、減少（それ未満） |
| 暮らし向きの見通し | 改善（+2ポイント以上）、横ばい（-2ポイント以上）、悪化（それ未満） |
| 収入と物価（1年） | 収入が物価を上回っている（+1ポイント以上）、収入と物価がほぼ同じ（-1ポイント以上）、収入が物価に追いついていない（それ未満） |
| 年金と物価（累積） | 収入が物価を上回っている（+2ポイント以上）、収入と物価がほぼ同じ（-2ポイント以上）、収入が物価に追いついていない（それ未満） |

### 収入と物価の比べ方

- **1年の比較：** 収入の前年比 − 物価の前年比（ポイント）。月次の家計の数字は直近3か月の平均どうしで比べます。四半期の収入は、同じ3か月の物価の前年比の平均と比べます。
- **累積の比較（年金）：** 1年ごとの差は小さくても積み重なるため、2021年4月を起点に、年金額と物価それぞれの上がり幅の差を見ています。起点は、今回の物価上昇が始まる前の年度としました。

### 確認ポイント

観点ごとの判定を組み合わせて、文章の「確認ポイント」を作っています。例えば「物価全体が上昇」かつ「年金が物価に追いついていない」とき、年金で暮らす世帯の目減りを指摘します。組み合わせの規則は `src/situation/phase.py` の `combine` にあります。

## 4. 世界の動きが届くまでの時間差

- 上流（例：円建ての原油価格）の前年比を0〜24か月ずらし、下流（例：北海道の灯油などの物価）の前年比との相関が最も高くなるずれを探します。
- 使うのは直近20年（240か月）で、重なる月が60か月未満のときは計算しません。
- 最も高いずれが探した範囲の上限（24か月）になったときは、「上限。参考程度」と表示します。
- 「見通し」は、そのずれと直線の当てはめから、下流の前年比がこの先どうなりそうかを示すだけのものです。予測ではありません。
- 相関は原因を示すものではありません。

## 5. 所得の階級別の比較

- 家計調査の「年間収入五分位」を使い、**二人以上の勤労者世帯**を年収の低い順に5つに分けて、手取り（可処分所得）の伸びと物価の伸びを比べています。月ごとの振れを抑えるため、どちらも12か月平均です。
- この5階級には、単身世帯、働いていない世帯、年金で暮らす世帯は含まれません。最も低い階級でも、世帯所得の中央値（国民生活基礎調査）に近い層にあたります。
- そのため、このグラフが示すのは「中央値前後から上の世帯にも、物価高の影響がどこまで及んでいるか」です。相談で多い年収100万円前後の世帯は、この統計の外にあり、次の節で別に扱います。
- 各階級を、平均年収で**低所得・中所得・高所得**に区分しています。法律上の統一した定義はないため、次の目安を使いました。
    - **低所得：** 年収300万円以下（生活実態や報道で使われる目安）。行政上の目安となる住民税非課税の年収は、2026年度・1級地で単身110万円、夫婦2人166万円、夫婦と子ども1人で約205万円、夫婦と子ども2人で約255万円、65歳以上・年金のみの単身で年金収入155万円です（自治体の級地で数万円異なります）。
    - **中所得：** 300万円を超え、世帯所得の中央値（451万円）の2倍（約900万円）まで。
    - **高所得：** それより上。
- 現在の数字では、5階級のうち下の3つが中所得、上の2つが高所得にあたり、**低所得にあたる階級はありません**。
- そこで低所得は、毎月の家計の統計の代わりに、**主な収入源の伸び**で示しています。
    - **最低賃金で働く人：** 北海道の最低賃金（時給）。フルタイム（年2,016時間）で換算すると年約220〜230万円で、低所得の目安（300万円以下）に入ります。北海道の物価と比べます。
    - **基礎年金だけで暮らす人：** 老齢基礎年金（満額で年約83万円、2025年度）。全国の物価と比べます。
    - 時給は上がっても、働ける時間が減れば年収は増えません。最低賃金の線は「時給の上がり方」であり、世帯の収入そのものではない点に注意が必要です。
- 物差しとして、国民生活基礎調査の世帯所得の中央値、貧困線、所得200万円未満の世帯の割合を、グラフの下に示しています（`config/income_reference.csv`）。

## 6. 統計の外にいる世帯

毎月の家計の統計は主に働いている世帯の数字で、相談で多い**年金で暮らす単身世帯**は含まれません。そこで、厚生労働省「年金制度基礎調査（老齢年金受給者実態調査）」（2022年11月1日時点、全国）の集計表を基準にしています。

- 単身の受給者の年金額・収入・支出・貯蓄・住まいの分布を、調査時点の値として使います。
- 調査時点から最新月までの**年金額の改定率**と**北海道の消費者物価指数**の上がり方を当てはめ、「調査時と同じ暮らしに、今は月いくら多くかかるか」を計算しています。
- 全国の数字であり、北海道の暖房費の重さは反映していません。調査はおおむね5年ごとのため、次の調査が出たら更新します。

## 7. 制度・出来事の年表と注記

補助・税・料金改定などは前年比を大きく動かします。年表（`config/events.csv`）に関係する指標を結び付け、次のような注記を自動で付けています。

| 状況 | 注記 |
|---|---|
| 最新月と前年同月の両方に補助がある | 価格が抑えられている。前年同月も補助あり |
| 最新月だけ補助がある | 価格が抑えられている。前年比は低めに出る |
| 前年同月だけ補助があった | 補助が終わったため、前年比は高めに出る |
| 直近12か月に税や料金の改定があった | その改定を含む |

給付（現金・ポイントなど）は価格を動かさないため、注記には使いません。出典で確認できていない出来事は「（要確認）」と表示します。

## 8. 限界

- 判定の基準と組み合わせの規則は、相談支援の経験にもとづく目安で、統計的に検証したものではありません。
- 地域は北海道全体（一部は北海道・東北）で、市町村ごとの違いは見ていません。
- 単身世帯の四半期の家計は調査世帯が少なく、振れが大きい数字です。
- 年金調査は2022年時点のもので、その後の分布の変化は反映していません。
