# 手入力・手置きデータ（data/manual）

## 1. 北海道消費生活モニター価格動向調査（hokkaido_monitor フォルダ）

北海道庁のページ「物価情報」から、毎月「石油製品の価格推移」のExcel（`04_suiiYYMM.xlsx`）をダウンロードし、
`data/manual/hokkaido_monitor/` にそのまま置きます。ファイル名は変えなくて構いません。

- 灯油・プロパンガス・ガソリンの価格を、全道と6つの圏域別に読み取ります。
- 古いファイルを残したまま新しいファイルを置いても大丈夫です。同じ月の値は、より新しい月まで載っているファイルの値を使います（訂正版にも対応）。
- 毎月末に公表されます（調査は毎月10日現在）。

## 2. 手入力のCSV

PDFなどでしか公表されていないデータは、手で入力して取り込みます（例: `HKD_JOBS_RATIO.csv`）。

1. 系列ごとに `<source_id>.csv` を1つ作ります。
2. 1行目は `date,value`、2行目からは「年月,値」を入力します。
   ```
   date,value
   2026-08,1.02
   2026-09,1.01
   ```
   日付は `2026-09`、`2026/9`、`2026年9月` のどれでも構いません。値の桁区切りのカンマは自動で取り除きます。
3. Excelで編集する場合は「CSV UTF-8（コンマ区切り）」で保存してください。
4. `config/series_catalog.csv` で、その系列の `active` を `1` にします。
5. `python main.py` を実行すると取り込まれます。

## 3. 年に1回などで変わる値（年金・最低賃金）

改定があった月だけを1行ずつ書き、`config/series_catalog.csv` の `source_options` に `fill=forward` と書きます。
次の改定までの月は、同じ値で自動的に埋めます（最後の値は今月まで続きます）。

- `PENSION_INDEX.csv`: 年金額の指数（2021年度=100）。毎年4月の改定率を前の行に掛けて、新しい行を足します。
  例: 改定率が+1.5%なら、前の行の値×1.015。`rate_pct` と `source` の列はメモ用で、計算には使いません。
- `HKD_MIN_WAGE.csv`: 北海道の最低賃金（時間額）。毎年の改定の発効月（例: `2027-10`）と金額を1行足します。

## 参照用の集計表（reference/）

- `reference/nenkin_2022/`: 年金制度基礎調査（老齢年金受給者実態調査）令和4年の集計表（e-Statからダウンロードしたまま）。
  EFPは直接は読みません。ここから取った数字を `config/households_outside.csv` に書いています。
  次の調査が公表されたら、新しいフォルダ（例: `nenkin_2027/`）に置き、CSVの数字と `survey_month` を更新します。
