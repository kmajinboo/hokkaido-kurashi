# このサイトについて

## 目的

生活困窮の相談では、本人や世帯の事情に目が向きがちです。しかし、物価やエネルギー価格、雇用、年金、制度の変化といった本人の外側の動きが、困りごとの一因になっていることがあります。

このサイトは、北海道の暮らしに関わる公表統計と制度の動きを毎月同じ方法で整理し、相談の背景として考えられる「外的な一因」を見えるようにする試みです。現在、研究者の方々に方法についてご意見をいただくために公開しています。

## 更新

- 月に一度、公表統計を取り直して月次レポートとグラフを更新します。
- 年表（制度・出来事）は、新しい制度が分かりしだい追加します。

## 注意

- 判定の基準は目安で、公的な基準ではありません。
- ここで示すのは、相談の背景にありうる一因です。個々の相談者の原因を示すものではありません。
- 相談者の個人情報は一切使っていません。
- 補助などの制度の内容は、出典で確認できたものと、確認中のもの（「要確認」と表示）があります。
