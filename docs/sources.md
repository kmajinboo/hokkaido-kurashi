# データの出典と利用条件

このサイトは、次の公表データを出典から取得して計算しています。データそのものは再配布していません。各データの利用条件は出典元の定めに従います。

## 出典元と利用条件

| 出典 | 主なデータ | 利用条件 |
|---|---|---|
| 政府統計の総合窓口（e-Stat）／総務省・厚生労働省ほか | 消費者物価指数、家計調査、労働力調査、職業安定業務統計、毎月勤労統計 ほか | 政府標準利用規約（出典を示せば利用可） |
| Federal Reserve Bank of St. Louis「FRED」（一部はIMF等の作成） | 原油価格、LNG価格、国際食料価格指数、為替、米国政策金利 | FREDの利用規約（系列ごとに作成元の条件あり） |
| 北海道「消費生活モニター価格動向調査」 | 灯油・プロパンガス・ガソリンの店頭価格（全道・地域別） | 北海道ホームページの利用条件 |
| 厚生労働省「年金制度基礎調査（老齢年金受給者実態調査）」令和4年 | 単身の年金受給者の年金額・収入・支出・貯蓄・住まいの分布 | 政府標準利用規約 |
| 厚生労働省「国民生活基礎調査」2025年（2024年の所得） | 世帯所得の中央値、貧困線、所得階級別の世帯の割合（グラフの「所得の物差し」） | 政府標準利用規約 |
| 住民税非課税の年収の目安（2026年度、1級地） | 低所得の区分の目安 | 各自治体の定め（級地で異なる） |
| 厚生労働省（年金額の改定）、北海道労働局（最低賃金） | 年金額の改定率、北海道の最低賃金 | 各機関の発表資料 |

制度・出来事の年表の出典は、「制度・出来事の年表」のページに行ごとに示しています。
